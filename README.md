# Customer Segmentation, Churn Prediction and Customer Lifetime Value

An end-to-end customer analytics project on UK online retail transactions. It segments customers with RFM and K-Means, predicts 90-day churn, estimates 12-month customer lifetime value (CLV), and ranks which customers to contact first in an interactive dashboard.

|---|---|
| Data cleaned | 1,067,371 raw rows → 796,590 clean transaction lines, 5,839 customers |
| Cancellations matched to orders | 15,681 of 18,744 (3,063 unmatched, documented) |

## Dataset

- **UCI Online Retail II:** transactions from a UK-based online retailer, December 2009 to December 2011. Download from the UCI Machine Learning Repository.
- **IBM Telco Customer Churn:** 7,043 customers with contract, service and billing fields. Download from Kaggle.

The two datasets share no customers, so the Telco model is a benchmark, not part of the segmentation analysis.

## Method

1. **Cleaning:** drop rows without a Customer ID. Match each cancellation to an earlier order for the same customer, product and price, and remove the matched quantity from that order. Remove postage, fees, manual adjustments and other non-product lines. Remove rows with zero or negative quantity or price.
2. **RFM segmentation:** recency, frequency and monetary value per customer, log-transformed, standardised and clustered with K-Means. k was chosen by silhouette score.
3. **Churn model:** features come from transactions before a cutoff (10 September 2011). The outcome is no purchase in the following 90 days. Logistic regression and gradient boosting are tuned with grid search and repeated cross-validation. The threshold is chosen on training data only. Segments are rebuilt from pre-cutoff data and checked against the outcome.
4. **Benchmark:** the same tuning method on the Telco dataset.
5. **CLV:** BG/NBD predicts purchase frequency and Gamma-Gamma predicts spend per order, as of the cutoff. Expected revenue at risk is churn probability multiplied by CLV. Single invoices above £50,000 are capped for CLV.
6. **Dashboard:** a Streamlit app that filters segments and churn risk, shows the segment summary, and downloads a ranked contact list.

## Setup and run

1. Install the requirements:
   ```
   pip install pandas numpy scikit-learn lifetimes streamlit
   ```
2. Open `Customer Segmentation + Churn Prediction_Base_Final.ipynb` in Jupyter and run all cells in order. This creates the files in `Output CSVs`.
3. From the `Projects` folder, start the dashboard:
   ```
   streamlit run app.py
   ```

The folder paths are written out in full at the top of the notebook and in `app.py`. If you move the project, update them in both places. After re-running the notebook, stop Streamlit (Ctrl+C) and start it again, because the dashboard caches the data it loads.

## Data notes

- Invoice 581483 (9 December 2011) contained 80,995 units of one item at £2.08, a total of £168,470. It was removed during cancellation matching and no longer affects the results.
- 3,063 cancellation lines could not be matched to an original order. Most had no earlier sale of that product to that customer, which suggests the original was recorded without a Customer ID.
- Postage, fees and manual adjustments (£232k) are excluded from revenue, so CLV measures product revenue only.

## Limitations

- **Revenue, not profit.** The dataset has no cost data, so CLV measures revenue.
- **Undiscounted CLV.** Future revenue is not discounted.
- **Conservative volume.** The purchase model underpredicts orders by about 21% on the holdout test, so CLV totals are likely understated.
- **Recency dominates churn.** Most of the churn signal comes from recency alone.
- **Churn definition.** No purchase in 90 days may count customers who buy less than quarterly as churned.
- **Separate datasets.** Telco results cannot be linked to UCI segments or CLV.
- **Time period.** Results reflect December 2009 to December 2011.
